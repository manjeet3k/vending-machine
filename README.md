****Sample Vending Machine****
- 

**About**
- It's an Application designed to demonstrate the working of a simple Vending Machine.
- It has only 3 types of items, Coke, Fanta and Sprite, all are drinks.

**Input Parameters**
- First Line contains 3 integers and are the quantities of Coke, Fanta and Sprite.
- Second line again contains 3 integers and are the price per unit for Coke, Fanta and Sprite.
- Third line too contains 3 different integers and are the button numbers assigned to each 3 drinks, sequentially for Coke, Fanta and Sprite.
- Next line contains an integer, n, that represent the number of queries.
- Next n lines each contains, two integers representing button number and the money used to make a query.

**How to run the application**
- Provide the input in sequence and observe the corresponding output.
